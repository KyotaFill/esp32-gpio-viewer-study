# KyotaFill study record

This standalone study repository preserves the Git history and MIT license of
[thelastoutpostworkshop/gpio_viewer](https://github.com/thelastoutpostworkshop/gpio_viewer).
The original code and authorship remain upstream work. KyotaFill's additions
are limited to this study record and commits whose subjects start with
`study:`. Their dates organize a reconstructed learning calendar and do not
claim authorship of the imported source code.
